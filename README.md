# Kronometër Ultra ⏱

Kronometër ultra-premium me milisekonda, xhiro (laps) dhe historik të ruajtur — 100% HTML/CSS/JS, pa asnjë server.

**Live:** https://erionnezha.github.io/Stopwatch-App/

## Veçori

- ⏱ Display gjigant HH:MM:SS.cs me font tabular dhe shkëlqim gold
- ▶ Fillo / ⏸ Ndalo me `requestAnimationFrame` + `performance.now` për saktësi maksimale
- 🏁 Xhirot: numri, koha e xhiros dhe diferenca nga e mëparshmja (xhiro më e shpejtë shënohet me ★)
- 📜 Historiku i sesioneve i ruajtur në `localStorage` (data, koha totale, nr. xhirosh)
- ⌨ Shkurtore tastiere: `Space` = fillo/ndalo, `L` = xhiro, `R` = reseto
- 📱 Responsive, UI plotësisht në shqip

## Si përdoret

Hap faqen dhe shtyp **Fillo**. Sesioni yt ruhet automatikisht në historik kur shtyp **Reseto** pas një matjeje.
